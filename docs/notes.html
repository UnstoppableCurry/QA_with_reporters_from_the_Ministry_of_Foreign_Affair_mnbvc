Evidence

本站写了什么，以及明确没写什么

这是一份静态说明，不是外交部官网，也不是在线语料浏览器。文字、数字和例子都能指回 README、Python 源码或 wget_url.txt。下面列出边界，避免把文档读成评测报告或授权声明。

采用的证据

  • 仓库 README：项目名称、脚本代际、Hugging Face 链接、shtml / 中英对照数量记载、清洗前后示例、MIT 许可证行。
  • 五个 Python 文件与 requirements.txt：字段名、切分正则、替换表、输入输出路径。
  • wget_url.txt：420 条 www.mfa.gov.cn URL，以及由路径读出的年月分布。
  • 对 README 所给 Hugging Face 地址的 HTTP 访问：确认该链接存在，并 307 重定向到同名数据集路径。

没有写进本站的内容

  • 未经仓库复算的新数据规模、token 数、语言比例。
  • 任何基准分数、模型效果、标注质量评估。
  • Hugging Face 下载量、点赞、使用者或机构背书。
  • 把 wget_url.txt 的 420 条等同于 353 / 1700 / 12877。
  • 把 README 清洗前残片说成清洗后 JSON 的原文。
  • 原始网页全文的版权归属、再分发许可，或「官方授权语料」一类主张。仓库只表明脚本处理公开网页/文档，以及 README 对本仓库脚本使用 MIT。
  • MNBVC 项目整体的组织架构或其它子集；名称只出现在 README 标题里。
