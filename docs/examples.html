对照示例：只展示 README 写过的文本

仓库没有样例截图。下面两组「清洗前 / 清洗后」都来自 README。需要先说清：shtml 组的清洗前讲东亚合作与东盟，清洗后讲李克强总理访柬；中英对照组的清洗前讲也门撤侨，清洗后讲亚投行。它们说明的是版式，不是同一条记录的变换。

若把左右两栏读成「这一段 HTML 被洗成了右边这条 JSON」，就会读错 README。本页把它们标成「版式样例 A / 版式样例 B」。

shtml 网页清洗 · 版式样例

清洗后字段拆解

instruction
「能否介绍李克强总理访问柬埔寨有关安排？你如何看待当前中柬关系？」——已是纯文本问句。老脚本会把提问里的「中方」换成「你」；本条原文用的是「你」。
output
一段连续中文答问，无 HTML 标签、无 答： 前缀。
date / title
2022-11-4 对应标题「2022年11月4日外交部发言人赵立坚主持例行记者会_中华人民共和国外交部」。同日 URL 也出现在 wget_url.txt：t20221104_10800749.shtml。本站不主张这条 JSON 一定抽自该 URL。

清洗前残片里能看见的噪声

  • 内联样式 FONT-SIZE: 14px：现行 答记者问.py 用 14问 当切分锚点，并在写出时删除 14。
  • 全角空格 　　：老脚本 replace('\u3000', ' ')。
  • 未闭合/异常的 /P：抽文本或 BeautifulSoup get_text() 后应消失。
  • 「答：」口语标记：切分键，不进入 output。

中英对照 · 版式样例

README 写「5 份文件，一共 38 条问答数据」。清洗前样例是也门撤侨的中英问答；清洗后样例是 2015 年 3 月 31 日华春莹记者会上关于亚投行的中英对象。两侧 output 都是数组。

这份 JSON 能对上的脚本行为

  • output 为两个字符串：与「按段落分流、多段回答进数组」一致。
  • 中英 date 同为 2015-3-31：与把「2015年3月31日」里的「年」「月」换成 - 一致。
  • 英文 instruction / title 两端留有空格：与源码未做 strip() 的赋值一致。
  • 中文提问仍写「中方」。docx 脚本不像 shtml 老脚本那样替换「中方」。

示例正文保持 README 用字，仅增加换行以便阅读。
