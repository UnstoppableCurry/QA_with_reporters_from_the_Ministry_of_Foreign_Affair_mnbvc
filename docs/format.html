数据格式：三种可核验的写出约定

README「数据格式」给出网页清洗与中英对照两类示例；现行 答记者问.py / 新闻发布会.py 则另写一套中文字段。下面按源码与 README 分列，不把它们说成已经互相迁移完成。

shtml / 网页记录

README 清洗后示例，以及 clear_shtml_data.py 写出的对象，字段一致。每条对应一次提问与一次回答；input 在源码里始终写成空字符串。

shtml 输出字段
字段 类型（源码字面） 含义（据脚本赋值）
input 空字符串 固定为 ''，脚本未填上下文。
instruction 字符串 记者提问。老脚本会去掉「发言人」，并把提问中的「中方」替换为「你」。
output 字符串 发言人回答。老脚本会把回答中的「中方」替换为「我方」，并截到第一个 </div>。
date 字符串 从页面 <title> 里「年 / 月 / 日」改写成 YYYY-M-D；标题不含日期时为空。
title 字符串 BeautifulSoup 取出的 title 文本。README 示例带「_中华人民共和国外交部」后缀。

中英对照嵌套对象

clear_docx_data.py 为每一对问答写出 {"en": …, "zh": …}。中英两侧字段名相同；output 是数组，因为脚本按段落把中文与非中文答句分开收集。

中英对照输出字段
路径 赋值来源（源码）
zh.instruction 「问：」之后、「Q:」之前的中文提问。
en.instruction 「Q:」之后、「答」之前的英文提问。
zh.output / en.output 「答：」之后按不间断空格切开；含汉字的段落进 zh，其余进 en。
*.date 标题里括号日期 （YYYY年M月D日），年/月替换为连字符。
zh.title 括号日期之前的中文标题。
en.title 括号日期之后的英文标题。

现行脚本字段

README 称 答记者问.py 与 新闻发布会.py 为「最新版本格式对齐」。源码写出的却是中文键，而不是 README 示例里的 instruction / output。两条流水线共用「问 / 答 / 元数据」，来源 字符串不同。

字段 答记者问.py 新闻发布会.py
id 从 10597 起递增 从 0 起递增
问 / 答 切分后的问答文本，再去掉 141、14、1267 等残留
来源 外交部答记者问 外交部新闻发布会
元数据.create_time 正文里匹配到的「YYYY年M月D日」，再交给 get_years 同样日期改写成 YYYYMMDD
元数据.回答明细 等 模板里留空字符串，主流程未赋值
输出文件 ./testsss.json（jsonlines 追加） ./data4shtml1.json（jsonlines 追加）

日期与标题

  • 老 shtml 脚本：日期只来自 HTML title，例如把「2022年11月4日…」切成 2022-11-4。与 README 示例一致。
  • docx 脚本：要求标题含 （YYYY年M月D日）。
  • 现行网页脚本：在抽出的中文正文里用正则 \d{4}年\d{1,2}月\d{1,2}日 找第一条；找不到则为 None。

因此「同一场记者会」在不同脚本里，日期字符串形态可能是 2022-11-4 或 20221104。这是源码差异，不是额外规范。

字段说明只对照 README 与 *.py 赋值语句。
