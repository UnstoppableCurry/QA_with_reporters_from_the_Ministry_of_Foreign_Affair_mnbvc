清洗逻辑：从网页标记到问答记录

README 把现行脚本概括为「正则清洗网页数据」。下面按文件把分支、分隔符和替换表写出来，便于对照源码，而不是用流程图假装已经产品化。

老版本 clear_shtml_data.py README：已废弃

1

读入 .shtml

遍历硬编码目录 /www/baidu/外交部/外交部问答/20180224-20230416外交部表态/raw/。目录名里的日期闭区间与 wget_url.txt 的年月跨度 201802–202304 一致。

2

标题与日期

若正文含 title，用 BeautifulSoup 取标题。标题含「年 / 月 / 日」时，取「日」前一段并把年、月换成 -。

3

先修 HTML 粘连

把 记者</strong><strong …>： 与 记者</strong><strong>： 收成 记者：，避免切分点落在标签中间。

4

两条问答切分

若同时出现 问： 与 答：，按 问： 切开，再在每段用 答： 分成提问 / 回答，回答截到 </div>。否则若出现 记者：，再按发言人姓名切开。

5

用过的发言人姓名

源码列表为：汪文斌、赵立坚、毛宁、华春莹、耿爽（均带中文冒号）。

6

媒体名截尾

内嵌 85 个媒体字符串（去重后 84 个；日报广播协会 重复一次），按长度降序排序后，用于去掉提问末尾的机构名。列表见源码 jizhes，本页不重抄以免与脚本漂移。

7

措辞替换后写 jsonlines

提问：删除「发言人」，「中方」→「你」。回答：「中方」→「我方」。全角空格改半角并 strip。写出 ./data.json。

老版本 clear_docx_data.py README：已废弃

1

拼接段落

读取 /www/baidu/外交部/外交部问答/中英对照/*.docx，把所有段落文本连成一篇。

2

按「问：」切块

第一块当作整份文件标题；其后每一块应含 Q: 与 答：。若 答 前无法拆出 Q:，脚本打印 error 仍继续。

3

中英答句分流

去掉 A: 后按不间断空格切段。用 [\u4e00-\u9fa5]+ 判断是否含汉字：有则进中文 output 数组，否则进英文数组。

现行正则脚本 README：最新版本

两条现行脚本都从 test/ 下的 .html 读入，先用正则只保留汉字、数字和部分标点，再按「问 / 答」附近的数字痕迹切分。进度打印里的分母写死为 1700，与 README 新版本文件数相同。

共同的文本抽出

答记者问.py 使用 [\u4e00-\u9fa50-9，。？！、\n]+；新闻发布会.py 与 t.py 不保留换行。英文字母不在保留集合里，因此现行网页脚本不会产出 README 那种英文字段。

答记者问.py 的切分

1

用 社记者 预检：切分后不足 3 段则跳过该文件。

2

再用 14问 切开。首尾两段丢弃。中间段按 ？\n14 拆成问、答。这里的 14 与 README 清洗前示例里的 FONT-SIZE: 14px 对得上：抽中文时字号数字会粘在「问」前面。

3

写出前再删 141、1414、14、1267，并把 。1 / ？1 收成句读。去掉换行。

新闻发布会.py 的切分

1

按 \d答 切开，再按 \d问 切开。

2

去掉连续 7 位及以上数字；再按 ？.{0,5}答 分开问句尾与答句。

3

若片段仍含「问」，再用标点加「问」二次切开。最后按奇偶配对问答，并跳过每篇末尾两条。

实现备注（源码可见，不是评测结论）。 答记者问.py 写了 from t import get_years，但同仓库 t.py 没有定义 get_years；同名函数写在 新闻发布会.py 里。 clear_wen() 使用 jieba，却在看到第一个词之后立即返回，且主流程未调用。新闻发布会.py 与 t.py 文件中部有一段与清洗无关的英文「倒车驾驶」JSON 字面量，未写入输出。
