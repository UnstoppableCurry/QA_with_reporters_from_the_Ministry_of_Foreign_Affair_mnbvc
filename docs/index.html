把带标签的记者会网页，收成可对齐的问答记录

本仓库是 MNBVC 项目下的通用清洗脚本集合，面向外交部记者问答网页与中英对照文档。本站不是交互式演示应用，而是依据 README 与源码整理的可读文本/数据说明：格式字段、清洗步骤、以及仓库里已经写出的清洗前后例子。

仓库里有什么

README 英文标题写作 MNBVC General Cleaning Script for the Q&A Dataset of Foreign Ministry Journalists。脚本按代际分成两组：

  • 已废弃：clear_shtml_data.py 清洗 .shtml，clear_docx_data.py 清洗中英对照 .docx。
  • 现行：答记者问.py 与 新闻发布会.py，对网页文本做正则切分，并写出 jsonlines。

发布后的语料在 Hugging Face 数据集 Iron-man/MNBVC-QA-with-reporters-from-the-Ministry-of-Foreign-Affairs。该地址为 README 给出的链接；访问时会重定向到同名数据集页 wangtianxin/…。本站不转载下载量、点赞或其他平台运营数字。

本地运行（README）

  1. 安装依赖：pip install -r requirements.txt
  2. 现行网页清洗：python 答记者问.py 或 python 新闻发布会.py
  3. 老版本脚本仍保留在仓库中，README 已标明废弃。
